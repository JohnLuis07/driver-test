# PanVK G615

Independent Mesa PanVK baseline for the Infinix GT 30 Pro (X6873), Mali-G615 MC6, Android 16 and Peanuts Native 0.1.8. The first target is Pokémon Legends: Z-A (`0100F43008C44000`).

Alpha 01 compiled in Codespaces and passed static Android ABI and Peanuts ZIP import checks. Device execution is pending. The [driver ZIP](dist/PanVK-G615-Alpha01.adpkg.zip), source archive, notices and checksums are in `dist/`.
